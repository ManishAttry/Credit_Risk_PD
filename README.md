# Credit Risk PD Prediction

## Overview

This project predicts the Probability of Default (PD) using machine learning and presents business insights through a Power BI dashboard.

## Features

- Data Cleaning
- Feature Engineering
- Logistic Regression
- Random Forest
- ROC Curve
- IFRS 9 Staging
- Power BI Dashboard

## Tech Stack

- Pandas
